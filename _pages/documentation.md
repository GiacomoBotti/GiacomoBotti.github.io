I created the documentation of some codes that I wrote. You will find them below

## Classical combination frequencies on a Morse Potential

One of the reviewers of [[Botti2025]](/publications#Botti2025) requested that I shared my codes in a [GitHub repository](https://github.com/GiacomoBotti/classical_combination_frequencies). Since I wanted to learn how to create a proper documentation website with [Read The Docs](https://about.readthedocs.com/), I created this:

[Classical Combination Frequencies: A Model System](https://classical-combination-frequencies.readthedocs.io/en/latest/)

## Dragonball suite for vibrational spectroscopy

I collaborated with Giacomo Mandelli (Politecnico di Milano) in the creation of Dragonball, a suite to compute classical vibrational density of states, starting from a guess geometry. We created a documentation website:

[Dragonball Suite](https://dragonball-vispec.readthedocs.io/en/latest/index.html)
